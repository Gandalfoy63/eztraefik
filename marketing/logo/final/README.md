# eztraefik logo: final files

Open **`preview.html`** to see everything. Concept: a z drawn as one route, from a deep blue start dot to an orange end dot.

## Which file to use
| Need | File |
|---|---|
| Website header, README, slides | `svg/static/lockup-light.svg` (light background) or `lockup-dark.svg` (dark) |
| Same, with the intro animation | `svg/animated/lockup-light-animated.svg` / `lockup-dark-animated.svg` (plays once) |
| Mark only (small spaces, avatars on your own background) | `svg/static/symbol-light.svg` / `symbol-dark.svg` |
| App icon | `svg/static/icon-light.svg` (blue tile) or `icon-dark.svg` (dark tile); `-square` versions for iOS, Android and Docker Hub, which round the corners themselves |
| Name only | `svg/static/wordmark-light.svg` / `wordmark-dark.svg` |
| One colour (print, stamps, embroidery) | `svg/static/symbol-mono-black.svg`, `-white`, `lockup-mono-black.svg`, `-white` |
| A raster image | `png/<symbol, icon, lockup, wordmark>/`: transparent, `-<size>.png` (square) or `-<height>h.png` |
| Chat, email, places without SVG | `gif/`: looping animation on a solid background, for example `lockup-light-1200.gif` |
| Website favicon and app icons | `web/`: `favicon.ico`, `favicon.svg`, `apple-touch-icon.png`, `icon-192/512.png`, `icon-maskable-512.png`, `site.webmanifest`, and `head-snippet.html` to paste in `<head>` |
| Docker Hub avatar | `web/dockerhub-avatar-1024.png` |

"light" = for light backgrounds, "dark" = for dark backgrounds. Animated SVGs show the finished logo when the viewer has reduced motion turned on.

## Rules
- **Clear space:** keep at least one dot diameter (52 units on the 256 grid, about 20 % of the mark) free around the logo.
- **Minimum size:** symbol and icon 16 px; lockup 24 px high on screen, 8 mm in print.
- Don't recolour the dots, swap their order, rotate or skew the mark, add effects (shadows, gradients, outlines), or set the name in another font. On photos, use the icon or a mono version.

## How it is built
Everything is generated by `../build/build.sh` from one geometry in `../build/make_svgs.py`: route z with a 30-unit stroke at exact 45°, dots of radius 26, on a 256 grid. Static masters are filled shapes (the route outlined, the wordmark converted to glyph outlines from Fira Sans 600 with fontTools), so they need no font. Animated files keep the route as a stroke so it can draw itself.

Animation (1.6 s): start dot pops in (0 to 320 ms), the request travels the z while the route draws (180 to 940 ms), it lands as the end dot with one ripple (900 to 1580 ms), the name rises in (620 to 1180 ms). The loop version holds the finished logo until 3.2 s.
