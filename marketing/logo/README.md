# eztraefik logo

**Final logo: [`final/`](final/)**. Open [`final/preview.html`](final/preview.html) to see every file.

The mark is a **z drawn as one route**: a request leaves the deep blue start dot, follows the blue path, and arrives at the orange end dot. It is the "z" of **ez**traefik and what the app does, routing traffic the easy way.

| Folder | What |
|---|---|
| `final/` | The real logo: SVG (static, animated once, looping), PNG at every size, GIF, web and platform icons. Usage rules in `final/README.md`. |
| `build/` | Scripts that generate everything in `final/` from one geometry. `build/build.sh` rebuilds it all. |
| `test/` | The exploration: concepts A / B / C, colour studies, the darker start dot, the first animation preview. Kept for reference. |
| `fonts/` | Fira Sans 600 (SIL Open Font License), used to outline the wordmark. |
