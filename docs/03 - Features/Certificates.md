# Certificates

Status: implemented in 0.2.0+3.

- **Resolvers**: ACME accounts with HTTP, TLS-ALPN or DNS challenge, email, optional private ACME server URL and its CA certificate (written to the shared volume and trusted through `LEGO_CA_CERTIFICATES`). DNS provider credentials are added as secret env vars. Saving needs Apply on the Traefik page.
- **Certificates**: ACME certificates read from each resolver's storage file ([ACMECerts](../../server/internal/traefik/certs.go#L33-L72)) and uploaded ones, with domains, issuer and expiry (warning at 14 days, error at 3).
- **Upload**: certificate + key PEM (paste or file), checked as a pair before saving ([ValidatePair](../../server/internal/traefik/certs.go#L89-L94)), served through the File provider's `tls.certificates`.

## New resolver
- **Name**: any text, like "My Website". It is saved as a slug (`my-website`), shown under the field, because Traefik flags and file names use it.
- **DNS Provider**: a list with completion over the 222 providers of [[00 - Downloaded Docs/lego/README|lego docs]], generated by [gen_dns_providers.py](../../tools/gen_dns_providers.py). Any other code can be typed. Choosing the DNS challenge starts on Cloudflare, so the variables show right away.
- **Variables**: the ones the provider needs open directly. Where lego lists alternatives, [NEEDED](../../tools/gen_dns_providers.py#L12-L19) names the usual sign-in, and all of them are required. For other providers one is enough, since the list may hold alternatives. A variable already set keeps its value when left empty. Add Variable covers anything else.
- **Advanced**: Propagation Seconds, [`dnsChallenge.propagation.delayBeforeChecks`](../../server/internal/traefik/container.go#L90-L95), and the private ACME server.

## Deleting
Deleting an uploaded certificate or a resolver takes it off whatever used it, never the routes ([detachCert](../../server/internal/api/resources.go#L595-L612), [detachResolver](../../server/internal/api/resources.go#L615-L629)). The confirmation lists the routes. They stay on HTTPS with another resolver if there is one, else Traefik's default certificate; turning HTTPS off would expose the app. Entrypoints and domains using a deleted resolver lose it too. Issued certificates have no delete button: they stay in the resolver's storage file. The files of a deleted upload stay on the shared volume, because Settings > History can bring the certificate back.
