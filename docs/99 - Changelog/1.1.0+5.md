# 1.1.0+5

Date: 2026-10-29. Type: MEDIUM (new feature). Previous: [[99 - Changelog/1.0.0+4|1.0.0+4]].

## What changed
- **Import from Nginx Proxy Manager** ([[03 - Features/Import from NPM|Import from NPM]]): connect with NPM's account (2FA supported), review every host with what it becomes and what changes, import the selection, switch NPM's ports to Traefik and back. Proxy hosts, custom locations, redirections, streams, access lists (password hashes copied from the NPM container), HSTS, Let's Encrypt (re-issued by Traefik) and uploaded certificates (copied).
- New sidebar item System > Import from NPM.
- Routes can target Traefik's own services such as `noop@internal` (used for redirections).
- Docker client: archive read, port bindings, network gateway ([[04 - Architecture/Docker Client|Docker Client]]).
- State: `migration` record ([[09 - Data/Data Model|Data Model]]). API: `/migrate/npm/*` ([[06 - API/API Overview|API Overview]]).
- Dev environment: a real NPM 2.15.1 under the `npm` profile and `dev/test_npm.py` ([[08 - Deployment/Dev Environment|Dev Environment]]).
- Downloaded docs: Nginx Proxy Manager 2.15.1 (docs and API schema), Go archive/zip and archive/tar, Docker Engine archive endpoint.

## Why
Asked: "a way to transfer the config of Nginx Proxy Manager to eztraefik".

## Verified
- Converter unit tests; `dev/test_npm.py` 26 / 26 (same answers through NPM, through Traefik after the switch, and through NPM after switching back); `dev/test.py` 28 / 28 afterwards; page checked at desktop and phone width.
- Not run against the real NPM on this host: that is yours to start from the Import page.
