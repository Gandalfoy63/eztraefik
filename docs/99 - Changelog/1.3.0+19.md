# 1.3.0+19

Date: 2026-10-30. Type: MEDIUM (new feature). Previous: [[99 - Changelog/1.2.9+18|1.2.9+18]].

## What changed
- **NPM import reads custom nginx config** instead of only warning about its first line: each directive becomes a named setting, is marked as not needed, or stays as a warning ([[03 - Features/Route Settings|Route Settings]]).
- **Route Settings in the route window**: Max Upload Size, Allowed IP Addresses, timeouts, headers, compression, path rewrite, redirects, with sliders for sizes and times. Shown in Generated config.
- Bug prevented: `RenderTransports` replaced the whole transports section; it now adds to it.
- Downloaded the nginx docs for the directives read.

## Not run
`dev/test.py` and `dev/test_npm.py`: the dev environment is stopped on request. Tested with unit tests and a throwaway Traefik, see [[03 - Features/Route Settings|Route Settings]]. Image not published.
