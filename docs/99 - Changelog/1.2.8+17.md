# 1.2.8+17

Date: 2026-10-29. Type: MINOR (bug fix). Previous: [[99 - Changelog/1.2.7+16|1.2.7+16]].

## What changed
- **NPM import skipped every host with a Let's Encrypt certificate** ("no email is known for a resolver") on a real NPM 2.15.1 with 60+ hosts: recent NPM versions no longer keep `letsencrypt_email` in certificate metadata, and the dev NPM's certificates were uploaded ones, so the tests never hit it. Now the new resolver falls back to the NPM account email used to sign in; the review says so and shows the email field, prefilled and editable ([[03 - Features/Import from NPM|Import from NPM]]). Plain HTTP hosts on a redirecting web entrypoint get HTTPS from that resolver instead of being skipped.
- Stream targets were shown as `://host:port`; now `host:port`.
- Unit test `TestLetsEncryptWithoutEmailUsesNPMAccount`. Image **1.2.8** published.

## Not run
`dev/test_npm.py` and `dev/test.py`: the dev environment is stopped on request.
