# 1.2.1+9

Date: 2026-10-29. Type: MINOR (style). Previous: [[99 - Changelog/1.2.0+8|1.2.0+8]].

## What changed
- The app uses the final logo ([[05 - UI-UX/Logo|Logo]]): app icon in the sidebar, the name with "ez" in brand blue, the animated lockup on sign-in and in setup (light or dark to match the theme).
- Full favicon set: `favicon.ico`, `favicon.svg`, Apple touch icon, PWA icons, `site.webmanifest`, theme colour. The Go server sends `.webmanifest` as `application/manifest+json`.
- README shows the logo.
- Headings that get focus from code (setup steps, page changes) no longer show a focus ring.

## Verified
Screenshots of sign-in (light and dark, during and after the animation), the sidebar expanded and collapsed, and the setup wizard on a fresh instance; content types of the manifest, favicon and logo files.
