# 1.2.0+8

Date: 2026-10-29. Type: MEDIUM (new brand identity). Previous: [[99 - Changelog/1.1.2+7|1.1.2+7]].

## What changed
- **Final logo** ([[05 - UI-UX/Logo|Logo]]): concept C, the z drawn as one route, deep blue start dot, orange end dot.
- `marketing/logo/final/`: 30 SVGs (static masters as filled shapes, animated once, looping; symbol, app icon, square icon, lockup, wordmark, one colour; light and dark), 122 PNGs (16 to 2048 px), 14 GIFs, web and platform icons, a preview page and a usage guide.
- `marketing/logo/build/`: the scripts that generate all of it from one geometry (`build.sh`).
- `marketing/logo/test/`: the exploration (concepts, colour studies, darker start dot, first animation), moved out of the final folder.
- Downloaded docs: fontTools 4.67.0. The docs checker now also checks the logo build scripts.

## Why
Asked: a real logo, then colour, then concept C with a darker first dot, an animation, and every format (SVG animated and static, PNG at every size, GIF, with and without text, light and dark), with the tests in their own folder.

## Not changed yet
The app (sidebar, favicon, login, setup) and the Docker Hub page still use the old mark.

## Files
`marketing/logo/` (see [[04 - Architecture/Code Map|Code Map]] for the build scripts), `tools/check_docs.py`, [VERSION](../../VERSION).
