# 1.0.0+4

Date: 2026-10-29. Type: MAJOR, first release: usable end to end as defined in [[01 - Vision/Plan|Plan]] section 7.

## What changed
- Version 1.0.0. No incompatible change from [[99 - Changelog/0.2.0+3|0.2.0+3]]; MAJOR marks the first usable release, as the versioning rules ask.
- Dockerfile cross-compiles for each target platform; arm64 build checked ([[08 - Deployment/Docker Image|Docker Image]]).
- Release image `eztraefik:1.0.0` and an exported tarball, publish script for amd64 + arm64.
- `dev/test.py` can run again on an environment it already set up ([[08 - Deployment/Dev Environment|Dev Environment]]).
- Overview: the services tile says "None yet" when there are none ([[03 - Features/Overview|Overview]]).
- Root `README.md` for the image and repository page.

## Verified
- Setup wizard clicked through in a real browser on a fresh environment.
- End-to-end test: 30 / 30 fresh, 28 / 28 repeat run.
- Go unit tests pass; web type check and build pass; vault check OK.

## Not verified
- Real Let's Encrypt on real ports 80 / 443 and real DNS. The dev environment uses Pebble, ports 18080 / 18443 and fake domains; ports 80 / 443 on this host belong to another proxy.
