# 1.8.0+30

Date: 2026-10-30. Type: MEDIUM (new feature). Previous: [[99 - Changelog/1.7.3+29|1.7.3+29]].

## What changed
- **Hard Refresh** on the Certificates page deletes every issued certificate and requests new ones, after a warning, with a progress bar and a way to restore the old ones ([[03 - Features/Certificates|Certificates]]).
- The Logs page hides tokens in URLs quoted by DNS provider errors.

## Tested
Unit tests [refresh_test.go](../../server/internal/api/refresh_test.go), [certs_test.go](../../server/internal/traefik/certs_test.go). The windows in a browser against a mocked API. A real Traefik v3.7.16 starts on an emptied storage file. Not run: the whole refresh on a real install, a real certificate request, `dev/test.py`, `dev/test_npm.py` (dev environment stopped on request). Image not published.
