# 1.5.0+22

Date: 2026-10-30. Type: MEDIUM (new features). Previous: [[99 - Changelog/1.4.0+21|1.4.0+21]].

## What changed
- **Docker**: containers grouped by stack, collapsible ([[03 - Features/Docker|Docker]]).
- **Domains**: `myhome.duckdns.org` is its own domain, using the Public Suffix List and repeated parts of hosts. This also fixes `example.co.uk` style names. The routes column is gone ([[03 - Features/Domains|Domains]]).
- **Routes**: the page uses the full width, names don't wrap, Ctrl+click opens the site ([[03 - Features/Routes|Routes]]).
- **Every table** sorts by clicking a column ([[05 - UI-UX/Components|Components]]). The default is name A to Z; logs and stats stay newest first.

## Tested
Unit tests [domains_test.go](../../server/internal/domains/domains_test.go). Docker, Domains and Routes in a browser against a mocked API: stacks, sorting, collapsing, plain click and Ctrl+click on the name and the row. Sorting on the other pages is covered by the type check only. Not run: `dev/test.py`, `dev/test_npm.py` (dev environment stopped on request). Image not published.
