# 1.4.0+21

Date: 2026-10-30. Type: MEDIUM (new features). Previous: [[99 - Changelog/1.3.1+20|1.3.1+20]].

## What changed
- **Deleting a certificate or resolver** takes it off the routes using it and keeps the routes on HTTPS. Deleting a resolver used by a route was refused before; a deleted upload left routes pointing at nothing. The confirmation lists the routes ([[03 - Features/Certificates|Certificates]]).
- **New resolver**: the name takes free text ("My Website", saved as a slug); DNS Provider is a list with completion over 222 providers, and free text; the variables it needs open directly; Advanced holds a Propagation Seconds slider.
- **Bug fixed**: Hetzner credentials were set as `HETZNER_API_KEY` in setup and NPM import. lego reads `HETZNER_API_TOKEN`, so the DNS challenge could not sign in.
- Escape in an open dropdown closes the dropdown, not the window. Downloaded lego's provider list.

## Tested
Unit tests [certs_test.go](../../server/internal/api/certs_test.go). Traefik v3.7.16 starts with the propagation flag. The whole window and the delete confirmation in a browser against a mocked API. Not run: `dev/test.py`, `dev/test_npm.py` (dev environment stopped on request), and a real DNS challenge. Image not published.
