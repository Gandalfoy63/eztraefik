# 1.6.0+25

Date: 2026-10-30. Type: MEDIUM (new feature). Previous: [[99 - Changelog/1.5.2+24|1.5.2+24]].

## What changed
- **New resolver window has a Domains field**, for `example.com` or `*.example.com`, also shown in the resolver table ([[03 - Features/Certificates|Certificates]]).
- **Route window**: the certificate cards became a dropdown ([[03 - Features/Routes|Routes]]).
- **Bug fixed**: a route on a domain with its own resolver was saved with the first resolver in the list. It now uses the domain's.
- **Bug fixed**: deleting a resolver left its domains marked wildcard, which could send a wildcard request to a resolver that can't issue one.

## Tested
Unit tests [certs_test.go](../../server/internal/api/certs_test.go). The resolver window and the route dropdown in a browser against a mocked API. Not run: a real certificate request, `dev/test.py`, `dev/test_npm.py` (dev environment stopped on request). Image published in [[99 - Changelog/1.7.1+27|1.7.1+27]].
