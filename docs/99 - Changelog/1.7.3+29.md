# 1.7.3+29

Date: 2026-10-30. Type: MINOR (release). Previous: [[99 - Changelog/1.7.2+28|1.7.2+28]].

## What changed
- The whole Git history was rewritten to replace real domains, a container name and a personal placeholder with neutral values, then force-pushed. Commit hashes changed; dates, messages and authors did not.
- Every published image was rebuilt from its cleaned commit: 1.1.1, 1.2.1, 1.2.7, 1.2.8, 1.3.0, 1.5.0 and 1.7.0, with their `1.1`, `1.2`, `1.3`, `1.5`, `1.7` and `latest` tags. Version numbers stay the same; the tags point to new digests.
- The NPM address placeholder moved to a documentation address, `192.0.2.10`, with the same rewrite.

## Checked
All 13 tags updated. The filesystem of the rebuilt 1.7.0 has none of the old values. No token or email address was found in the history.

## Not removed
Old commits may stay reachable by hash on GitHub until it cleans up, and old images by digest on Docker Hub. Existing clones and pulled images keep their copies.
