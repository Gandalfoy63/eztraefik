# 0.2.0+3

Date: 2026-10-29. Type: MEDIUM (the whole app, first working build). Previous: [[99 - Changelog/0.1.1+2|0.1.1+2]].

## What changed
- **Backend** in Go, standard library only: REST API, Docker Engine client, Traefik container management with fallback, dynamic config writer, ACME certificate reader, Prometheus collector, sessions and PBKDF2 passwords, JSON store with history. See [[04 - Architecture/Overview|Architecture Overview]].
- **Web UI** in React + TypeScript + Vite, on the approved style ([[05 - UI-UX/Style|Style]], now binding): every feature in [[03 - Features/Features Index|Features Index]] is implemented. Route window with Common and Certificates tabs as approved.
- **Dev environment** with fake domains `*.ezt.test`, fake ports 18080 / 18443 / 15432 / 15353 and Pebble as ACME server, plus an end-to-end test: 30 of 30 checks pass ([[08 - Deployment/Dev Environment|Dev Environment]]).
- **Docker image**: three-stage build, 19 MB distroless ([[08 - Deployment/Docker Image|Docker Image]]); production compose ([[08 - Deployment/Install|Install]]).
- **Downloaded docs** for Go, Docker Engine API, React, Vite, TypeScript, lucide-react, Docker build / Compose, Pebble, whoami ([[02 - Tech/Stack|Stack]]). The Traefik README now points at `configuration-options` (its CLI and env reference pages are empty upstream).
- **Tools**: `tools/relink.py` keeps code line links right; `tools/check_docs.py` now also checks the `Docs:` comment of every source file.
- Fonts self-hosted.

## Why
"Start building", with the decisions in [[01 - Vision/Plan|Plan]] section 6.

## Found while testing
- An HTTP-only route on an entrypoint that redirects everything never answers. eztraefik now refuses that combination in both directions ([[03 - Features/Routes|Routes]]).
- A stacked status-code chart failed the colorblind palette check; Stats uses one measure per chart ([[05 - UI-UX/Charts|Charts]]).
- The Overview counted eztraefik's redirect helper routers; they are excluded.
- The route window listed a route's own certificate as a separate choice; it is now part of its resolver option.

## Files
All new: see [[04 - Architecture/Code Map|Code Map]] for every file and its note. Changed: `VERSION`, `CLAUDE.md`, `.gitignore`, `tools/check_docs.py`.
