# 1.7.0+26

Date: 2026-10-30. Type: MEDIUM (new feature). Previous: [[99 - Changelog/1.6.0+25|1.6.0+25]].

## What changed
- Saving a resolver opens a window that offers to apply it to Traefik right away and checks DNS and the certificate of each of its domains ([[03 - Features/Certificates|Certificates]]).

## Tested
The window in a browser against a mocked API at 1280 and 360 px: nothing applied before the click, a failed apply and its retry, and each domain state. Not run: a real apply, a real certificate request, `dev/test.py`, `dev/test_npm.py` (dev environment stopped on request). Image published in [[99 - Changelog/1.7.1+27|1.7.1+27]].
