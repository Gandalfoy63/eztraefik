# 1.1.2+7

Date: 2026-10-29. Type: MINOR (configuration and docs). Previous: [[99 - Changelog/1.1.1+6|1.1.1+6]].

## What changed
- Image **1.1.1+6 published on Docker Hub** as `gandasdevstudio/eztraefik:1.1.1`, `:1.1` and `:latest`, for amd64 and arm64 ([[08 - Deployment/Docker Image|Docker Image]]).
- Both compose files now default to the published image, so they run without building ([[08 - Deployment/Install|Install]], [[08 - Deployment/Compose Example|Compose Example]]).
- README links the Docker Hub page.

The code is the same as 1.1.1+6, so no new image was pushed for this version.
