# 0.1.1+2

Date: 2026-10-28. Type: style change (MINOR).

## What changed
- In the preview, "New route" is now a centered window with **Common** (Name, Domain, Forwarding to: container or IP plus port) and **Certificates** (HTTPS, matching certificates or generate new, redirect) tabs. It replaces the side panel.
- Mobile: routes table shows the rule under the name; fixed a horizontal overflow and the breadcrumb slash.

## Why
Asked for in the style review.

## Decisions recorded
- Backend: Go (the fastest of the options with first-class Docker and Traefik libraries). eztraefik owns the Traefik container. "Custom APIs" means routing to external URLs. Notes for these still need updating.
