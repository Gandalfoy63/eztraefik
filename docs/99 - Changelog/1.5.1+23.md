# 1.5.1+23

Date: 2026-10-30. Type: MINOR (release). Previous: [[99 - Changelog/1.5.0+22|1.5.0+22]].

## What changed
- Image **1.5.0** (built from 1.5.0+22, which includes 1.4.0+21) published for `linux/amd64` and `linux/arm64`, also as `1.5` and `latest`. The compose files and the Docker Hub overview now use it. The application code is unchanged, so there is no new image for this version.
