# 1.2.7+16

Date: 2026-10-29. Type: MINOR (bug fix). Previous: [[99 - Changelog/1.2.6+15|1.2.6+15]].

## What changed
- **Setup offered eztraefik itself as a Traefik to replace.** Detection matched any image containing "traefik", and `gandasdevstudio/eztraefik` does. Choosing it made eztraefik stop its own container in the middle of setup: the browser showed "Setup saved, but Traefik did not start. NetworkError" and Traefik was never created. Found by the owner on a real install.
- Now images are matched on their name without the registry path, eztraefik images and eztraefik's own container are never listed, and asking to replace eztraefik's container is refused **before** anything is saved ([[03 - Features/Onboarding|Onboarding]]).
- Unit test `TestIsOtherTraefik`. Checked on a throwaway instance with the Docker socket: nothing offered, the refusal returns a field error, eztraefik keeps running, and setup stays open.
- Image **1.2.7** published (`1.2.7`, `1.2`, `latest`); compose files and docs point at it.

## Not run
`dev/test.py`: the dev environment is stopped on request while the owner sets up their own install.
