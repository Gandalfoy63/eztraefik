# 1.8.1+31

Date: 2026-10-30. Type: MINOR (release). Previous: [[99 - Changelog/1.8.0+30|1.8.0+30]].

## What changed
- Image **1.8.0** (built from 1.8.0+30) published for `linux/amd64` and `linux/arm64`, also as `1.8` and `latest`. The compose files and the Docker Hub overview now use it. The application code is unchanged, so there is no new image for this version.
